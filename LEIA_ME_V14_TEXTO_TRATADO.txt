- GuarujÁ
- BalneÁrio

Foi criada uma camada visual no JavaScript para tratar:
- cidades

- opções dos filtros
- dados de localização no card

- Não altera filtros.
- Não altera consumo.
- Não altera Plataforma Corretores.
