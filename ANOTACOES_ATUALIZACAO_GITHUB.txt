RH IMOB | Evolução visual do site de vagas + compartilhamento com arte
Data: 2026-05-11

O QUE FOI EVOLUÍDO NESTA VERSÃO

1) Hierarquia visual dos CTAs
- Mantido "Ver oportunidades" como CTA principal.
- "Entrar no banco de talentos" segue como CTA secundário.
- "Anunciar minha vaga" ficou com acabamento mais leve para não competir com o CTA principal.
- Os botões do site ficaram mais consistentes em sombra, foco, hover e acabamento geral.

2) Compartilhamento mais claro para a vaga
- O botão dos cards agora deixa mais explícito o objetivo:
  "Compartilhar arte da vaga"
- O card também explica melhor o que acontece:
  - Tenho interesse = abre WhatsApp do responsável
  - Compartilhar = gera arte visual e mantém o link individual da vaga

3) Melhoria visual dos cards das vagas
- Cards com hover mais elegante
- Cabeçalho da vaga com presença visual melhor
- Ações mais bem organizadas
- Melhor leitura entre resumo, metadados, detalhes e ações

4) Hero da página de vagas mais explicativo
- Abertura da página agora explica melhor que cada vaga pode ser compartilhada com:
  - arte visual pronta
  - link individual
  - candidatura direta para o WhatsApp do responsável

5) Modal de compartilhamento mantido e refinado
- Continua abrindo a arte visual da vaga
- Continua permitindo:
  - Compartilhar arte
  - Baixar arte
  - Copiar link da vaga

ARQUIVOS ALTERADOS

- vagas.html
- styles.css
- script.js
- ANOTACOES_ATUALIZACAO_GITHUB.txt

COMO SUBIR NO GITHUB

1) Descompacte este ZIP.
2) Suba os arquivos na raiz do repositório do site.
3) Confirme se a pasta api continua na raiz:
   api/vaga-preview.js
4) Aguarde o deploy da Vercel.
5) Teste:
   https://www.rhimob.com.br/vagas.html
   https://www.rhimob.com.br/vaga/gerente-vendas-osasco

TESTES IMPORTANTES

1) Abrir a página de vagas.
2) Confirmar se as vagas aparecem normalmente.
3) Validar o visual dos botões e dos cards.
4) Clicar em "Tenho interesse".
5) Clicar em "Compartilhar arte da vaga".
6) Validar se o modal abre com a arte.
7) Testar:
   - Compartilhar arte
   - Baixar arte
   - Copiar link

OBSERVAÇÃO IMPORTANTE

O WhatsApp não recebe HTML visual customizado enviado diretamente pelo site.
Por isso a solução prática implementada continua sendo:
- gerar uma arte em imagem da vaga
- manter o link individual para preview do site
