RH IMOB | Atualização do site - Vagas Supabase sem suposição
Data: 2026-05-11

O QUE FOI CORRIGIDO

1) A listagem de vagas do site foi ajustada para usar exatamente a estrutura real da tabela public.site_vagas_publicas enviada:

vaga_id
titulo
categoria
localidade
cidade
estado_uf
modalidade
remuneracao
horario
resumo
destaques
detalhes
requisitos
atividades
selo
prioridade
status
imagem_url
video_url
instagram_url
midia_tipo
midia_alt
responsavel_nome
responsavel_whatsapp
responsavel_empresa
responsavel_cargo
responsavel_email

2) O site não consulta mais colunas que não fazem parte da estrutura enviada, como:

id
slug
vaga_slug
imagem_og
og_image
image_url
imageUrl

3) O identificador público da vaga agora é sempre vaga_id.

Exemplo:
https://www.rhimob.com.br/vaga/gerente-vendas-osasco
https://www.rhimob.com.br/vaga/sdr-consolacao
https://www.rhimob.com.br/vaga/corretor_centro_mcmv_ajuda_custo_01

4) A função do Vercel api/vaga-preview.js agora busca a vaga por:

vaga_id = valor da URL
status = ATIVA

5) A listagem principal do site busca somente:

status = ATIVA
order = prioridade.asc, updated_at.desc

6) O botão Compartilhar vaga usa /vaga/{vaga_id}.

7) O botão Tenho interesse usa responsavel_whatsapp da vaga. Se a vaga não tiver responsavel_whatsapp, usa o fallback técnico do site.

ARQUIVOS ALTERADOS

script.js
api/vaga-preview.js
ANOTACOES_ATUALIZACAO_GITHUB.txt

COMO SUBIR NO GITHUB

1) Descompacte este ZIP.
2) Suba os arquivos na raiz do repositório do site.
3) Confirme que a pasta api está na raiz:

api/vaga-preview.js

4) Aguarde o deploy da Vercel.
5) Teste:

https://www.rhimob.com.br/vagas.html
https://www.rhimob.com.br/vaga/gerente-vendas-osasco
https://www.rhimob.com.br/vaga/sdr-consolacao

OBSERVAÇÃO IMPORTANTE

A rota /vaga/:slug continua existindo, mas o valor depois de /vaga/ agora é o vaga_id real, não uma coluna slug do Supabase.
