RH IMOB | Pacote limpo para atualizar GitHub via CMD

O QUE TEM AQUI

1) ARQUIVOS_SITE
Pasta com os arquivos limpos e atuais do site para subir no GitHub.

2) ATUALIZAR_GITHUB_RHIMOB.cmd
Script para Windows/CMD que copia os arquivos limpos para o seu repositório local, remove arquivos antigos/duplicados e pode fazer commit/push.

COMO USAR

Opção mais simples:
1. Extraia este ZIP em uma pasta qualquer.
2. Clique duas vezes em ATUALIZAR_GITHUB_RHIMOB.cmd.
3. Quando pedir, cole o caminho da pasta local do seu repositório GitHub.
4. Confirme com S.
5. O script vai limpar a pasta do repositório e copiar somente o site limpo.
6. No final, ele pergunta se você quer fazer commit e push.

Exemplo de caminho:
C:\Users\Fernando\Documents\GitHub\rh_imob_sucesso-main

Opção via CMD:
ATUALIZAR_GITHUB_RHIMOB.cmd "C:\Users\Fernando\Documents\GitHub\rh_imob_sucesso-main"

IMPORTANTE

- A pasta informada precisa ser um clone Git local e precisa ter a pasta .git.
- O script preserva .git, node_modules e .vercel.
- O script remove arquivos antigos e duplicados que não existem em ARQUIVOS_SITE.
- Não rode em uma pasta errada.
