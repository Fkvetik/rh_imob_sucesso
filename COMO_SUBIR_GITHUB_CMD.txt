Como subir no GitHub via CMD

1. Extraia este ZIP.
2. Copie TODO o conteúdo da pasta extraída para a raiz do repositório local do GitHub.
3. No CMD, dentro da pasta do repositório:

git add .
git commit -m "Ativa eventos Google Ads e adiciona anunciar vaga na home"
git push

Depois aguarde o Vercel publicar.
