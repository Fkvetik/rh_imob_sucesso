Política de Privacidade — RH IMOB Aceleradora

Última atualização: 21 de agosto de 2026

A Aceleradora RH IMOB ajuda a equipe a organizar a abordagem de contatos — candidatos publicados na Catho ou uma base própria do operador (ex: carteira de clientes para prospecção de venda). Esta página explica quais dados a extensão acessa, para que servem e como são tratados.

O que a extensão faz

  • Coleta os currículos exibidos na página de resultados de busca da Catho, a partir de um link de filtro configurado pelo operador
  • Permite importar uma base própria do operador (upload de CSV/planilha) — ex: carteira de clientes para prospecção de venda
  • Organiza os contatos coletados por operador, evitando duplicidade
  • Automatiza o envio de mensagens de abordagem via WhatsApp Web, com texto configurável pelo operador conforme a finalidade (recrutamento ou venda), respeitando intervalo entre envios
  • Acompanha o funil de contato em um painel Kanban (Novo → Enviado → Agendado → Encerrado)

Quem opera a extensão

Esta extensão foi desenvolvida para uso exclusivo da equipe RH IMOB (rhimob.com.br). Quando o contato coletado vem da Catho, o uso é restrito a recrutamento imobiliário. Quando o contato vem de uma base própria enviada pelo operador (upload de CSV), o uso pode incluir prospecção comercial de clientes da própria carteira do operador. Os dados coletados ficam armazenados em banco de dados privado da empresa. Não é distribuída para uso do público em geral.

Quais dados a extensão coleta

Ao rodar em uma página de currículo individual da Catho (catho.com.br) — nunca fora desse domínio — a extensão extrai os dados exibidos publicamente naquela página, incluindo, quando presentes:

  • Nome completo
  • Telefone(s) e e-mail
  • Cargo de interesse / profissão
  • Pretensão salarial e último salário informado
  • Data de nascimento, idade, sexo e estado civil
  • CEP, endereço, bairro, cidade e UF informados
  • Resumo do currículo, qualificações, experiência profissional e idiomas

Esses dados são inseridos pelo próprio candidato na Catho ao publicar seu currículo, dentro dos termos de uso daquela plataforma. A extração só ocorre quando um operador autorizado navega até essa página com um filtro de busca configurado por ele — a extensão não roda em segundo plano em outros sites.

Ao upload de uma base própria do operador (CSV), apenas dois campos são lidos e usados: nome e telefone. Nenhum outro dado é extraído desse arquivo.

Além disso, operadores autorizados podem consultar o Banco de Talentos — uma base compartilhada, mantida em um banco de dados separado (projeto "Novos Talentos"), com candidatos já mapeados anteriormente. Os resultados de busca aparecem com nome/contato mascarados; ao "liberar" um candidato selecionado, o contato completo é revelado e descontado de uma cota mensal contratada pela empresa. Essa base é usada exclusivamente para recrutamento.

Para que os dados são usados

  • Organizar os contatos coletados por operador, evitando abordagem duplicada
  • Permitir o envio de mensagem de abordagem via WhatsApp Web — de recrutamento (candidatos da Catho) ou comercial (contatos da base própria do operador)
  • Acompanhar o andamento do contato em um painel de gestão (Kanban)
  • Registrar agendamentos (entrevista ou reunião comercial) feitos pelo operador com o contato
  • Gerar indicadores internos de desempenho do funil (ex: quantos contatos abordados, agendados e convertidos) — sempre agregados, nunca usados para avaliar o candidato ou cliente individualmente

A extensão não usa esses dados para nenhuma outra finalidade além do processo de recrutamento ou prospecção comercial da própria RH IMOB — não são usados para pontuação de crédito, concessão de empréstimo, publicidade a terceiros ou qualquer outro fim.

Onde os dados ficam armazenados

  • Banco de dados privado da RH IMOB (Supabase): os contatos coletados/importados e os dados operacionais (login do operador, fila de envio, andamento do funil, agendamentos) ficam em um banco de acesso restrito.
  • Banco de dados do Banco de Talentos (Supabase, projeto separado "Novos Talentos"): a base compartilhada de candidatos consultada pela função "Banco de Talentos", com controle de acesso e cota próprios.
  • Planilha Google (Google Sheets, via Apps Script): uma cópia de cada contato coletado/importado também é enviada, em segundo plano, para uma planilha interna, para facilitar a consulta pela equipe sem precisar acessar o banco diretamente. Esse envio é apenas de saída (a planilha não é lida de volta pela extensão).

Nenhum dado é enviado para servidores ou serviços fora dos listados acima.

Envio de mensagens no WhatsApp

A extensão automatiza o envio de mensagens de abordagem navegando para o link oficial de composição do próprio WhatsApp Web (web.whatsapp.com/send?phone=...&text=...) e clicando no botão de enviar já existente na interface — não é usada nenhuma API não-oficial do WhatsApp. A extensão não lê o histórico de conversas, não lista os contatos salvos e não acessa credenciais/token de sessão do WhatsApp.

Para vincular automaticamente uma conversa aberta ao contato certo no painel de acompanhamento, a extensão identifica apenas o número de telefone da conversa que já está aberta na tela (via estrutura interna do próprio WhatsApp Web) — isso não envolve ler mensagens, nem enumerar a lista completa de conversas/contatos do operador.

Compartilhamento com terceiros

A RH IMOB não vende, aluga nem compartilha os dados coletados com terceiros. O acesso é restrito aos operadores autorizados da própria empresa.

Por padrão, cada operador só visualiza os contatos que ele mesmo coletou/importou. Uma equipe restrita de administradores da RH IMOB, com login próprio e separado do login de operador, também pode consultar um histórico consolidado de eventos (nome do contato, telefone e mudanças de status) de todos os operadores, para fins de supervisão operacional e suporte.

Retenção e exclusão de dados

Os dados coletados ficam armazenados enquanto forem relevantes para o processo de recrutamento ou de abordagem comercial em andamento. Qualquer candidato ou cliente pode solicitar a remoção de seus dados a qualquer momento pelo contato abaixo.

Permissões técnicas utilizadas

  • storage: guarda localmente a sessão do operador logado e as configurações de coleta
  • tabs: abre e gerencia as abas da Catho, WhatsApp Web e do painel de acompanhamento
  • scripting: executa o script de extração de dados na página de resultados da Catho
  • alarms: agenda a coleta automática no horário configurado pelo operador

Contato

Dúvidas sobre esta política ou solicitações relacionadas aos seus dados podem ser enviadas para contato@rhimob.com.br ou pelo WhatsApp da RH IMOB.
