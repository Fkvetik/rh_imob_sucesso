COMO PUBLICAR

1. Copie estes arquivos para a raiz do repositório rh_imob_sucesso, substituindo os existentes:
   - script.js
   - styles.css
   - vagas.html
   - index.html

2. No CMD, dentro da pasta do repositório com .git:
   git add .
   git commit -m "Corrige compartilhamento individual de vagas"
   git push

3. Depois que o Vercel publicar, teste:
   /vagas.html
   Clique em “Compartilhar vaga”.

4. O link esperado terá este formato:
   /vagas.html?vaga=corretor-locacao-alto-padrao#vagas
