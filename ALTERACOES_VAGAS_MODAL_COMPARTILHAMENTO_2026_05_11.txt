ALTERAÇÕES - VAGAS / MODAL SIMPLES / COMPARTILHAMENTO ESPECÍFICO
Data: 2026-05-11

Objetivo:
- Simplificar o fluxo de interesse em vagas do site.
- Evitar formulário grande para candidato que já clicou em uma vaga específica.
- Fazer a mensagem de WhatsApp sair com os dados da vaga já preenchidos.
- Manter compartilhamento com link específico da vaga.

Arquivos alterados:
- index.html
- vagas.html
- script.js

Ajustes aplicados:
1. Modal de interesse em vaga simplificado.
   Antes pedia: nome, WhatsApp, cidade/bairro, experiência, disponibilidade e mensagem complementar.
   Agora pede apenas:
   - Nome completo
   - Disponibilidade para início

2. Mensagem de WhatsApp da vaga ficou mais objetiva.
   Agora inclui automaticamente:
   - Vaga
   - Local
   - Modalidade/condição
   - Remuneração
   - Horário/rotina, se houver
   - Responsável
   - Link específico da vaga
   - Nome do interessado
   - Disponibilidade para início

3. Compartilhamento de vaga mantido com URL específica.
   O botão Compartilhar vaga usa link no formato:
   /vagas.html?vaga=ID_DA_VAGA#vagas
   Ao abrir, o site destaca a vaga correspondente.

Observação importante:
- Este ajuste cria link específico e mensagem bonita para compartilhamento.
- Para o WhatsApp gerar preview visual 100% específico por vaga, com imagem/título/descrição próprios no card do link, será necessário criar páginas estáticas individuais por vaga ou uma rota dinâmica no Vercel com meta tags Open Graph renderizadas no servidor.
- No modelo atual client-side com Supabase, o WhatsApp tende a ler o HTML base da página, não o conteúdo carregado por JavaScript.

Validação técnica:
- node --check script.js: OK
- node --check google-ads-events.js: OK
