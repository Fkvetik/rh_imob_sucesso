RH IMOB - GitHub completo com Plataforma Corretores

COMO USAR
1. Extraia este ZIP.
2. Envie todos os arquivos da pasta para a raiz do repositório GitHub Fkvetik/rhimob0305.
3. Substitua arquivos existentes quando o GitHub perguntar.
4. Aguarde o deploy automático da Vercel.
5. Acesse:
   https://rhimob0305.vercel.app/
   https://rhimob0305.vercel.app/corretores.html
   https://rhimob0305.vercel.app/vagas.html

IMPORTANTE
Este pacote mantém o site existente e apenas incrementa a seção Plataforma Corretores.
Não remove a home, não remove vagas, não remove política, não remove assets.

ARQUIVOS NOVOS
- corretores.html
- corretores.css
- corretores.js
- supabase-config.js
- ALTERACOES_PLATAFORMA_CORRETORES_2026_05_06.txt

ARQUIVOS ALTERADOS
- index.html
- styles.css
- sitemap.xml

SEGURANÇA
- Este pacote NÃO contém service_role.
- O arquivo supabase-config.js contém apenas a publishable key, correta para leitura pública com RLS.
